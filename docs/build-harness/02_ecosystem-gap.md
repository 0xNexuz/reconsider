# Ecosystem gap

Status: INFERRED opportunity; architecture PLANNED.

Existing capabilities: YouCam generates apparel previews; exchange platforms manage return choices and balances. Proposed contribution: combine reason-specific constraints, personal visualization, and a revalidated exchange request in one short flow.

Alternatives and historical overlap are cited in the research brief. KeepMe overlaps on image trust; ConfidFit overlaps on merchant try-on; ReturnGO and Loop cover commerce. No claim of market-wide uniqueness is justified.

Portability: another image provider could technically implement previews. YouCam is appropriate because apparel reference-image VTO is essential to the selected workflow and matches the event. Removing it removes the personal comparison, although ordinary refunds still work.

Defensibility would require merchant integrations, useful evaluation data, and demonstrated customer outcomes. None exists yet. The hackathon creates a deadline, not proof of market demand.
